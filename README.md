# Домашние задания по математике

Алгебра и геометрия, 7 класс. Первая домашняя работа: 10 примеров и 7 задач.

Статический сайт без регистрации. Ответы проверяются в браузере.
Сейчас прогресс сохраняется только на текущем устройстве в текущем браузере.
Оформление в духе блочных игровых миров: оригинальный персонаж и платформы,
оранжевая и голубая палитра. Графика находится в world.svg, стили в game.css.
Задания 2–5 пока не добавлены. На сайте нет персональных данных ученика.

Подготовлена синхронизация с отдельным хранилищем и режим просмотра учителя:
ответы, число попыток, история ошибок. Она пока отключена (sync-config.js),
поскольку доступ к обработчику без входа ещё не разрешён владельцем.
Персональные ключи доступа и серверные секреты в этом репозитории не хранятся.

Размещение: GitHub Pages, ветка main, корневая папка.
Все ссылки относительные; сайт работает и по адресу репозитория.

Проверка логики: `node --test --test-isolation=none tests/checker.test.mjs tests/sync.test.mjs`.

Задания для домашней работы — авторские учебные примеры по темам первых занятий.
Это не официальный вариант ВПР. Структура курса сверялась с образцами ФИОКО,
учебниками Макарычева и Атанасяна.
